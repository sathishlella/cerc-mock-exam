# CERC Mock Exam

An interactive practice exam for the **Certified ESG Reporting Consultant (CERC)** programme, a Malaysian sustainability reporting certification covering Bursa Malaysia listing requirements and the international frameworks behind them.

Fifty multiple-choice questions matching the real paper's format, with an explanation on every option, not just the correct one.

## Using it

Open `index.html` in any browser, or visit the hosted page. There is nothing to install and no build step. The whole thing is a single self-contained HTML file with no external requests.

**Study mode** reveals the explanations the moment you answer, with no timer.

**Exam mode** gives you 50 questions in 60 minutes with no feedback until you submit, matching the real exam's pacing of roughly 72 seconds per question.

Results break down by topic and flag anything below the 70% pass mark.

## Exam format this mirrors

| | |
|---|---|
| Questions | 50 |
| Time | 60 minutes |
| Pass mark | 70%, so 35 of 50 |
| Delivery | Online, link emailed the night before |
| Results | Released roughly a week after sitting |

## Question coverage

Weighted by how much of the course manual each topic occupies.

| Topic | Questions |
|---|---|
| Carbon Footprint & Net Zero | 9 |
| Bursa, NSRF & IFRS S1/S2 | 9 |
| GRI Standards | 8 |
| ESG & SDGs | 4 |
| Materiality: Impact vs Financial | 4 |
| Material Threats & Opportunities | 4 |
| ESG & Sustainability Reporting | 4 |
| Stakeholder Engagement | 3 |
| Greenwashing & Terms | 3 |
| ESG Governance | 2 |

Thirteen questions are tagged `mock` in the interface. Those mirror concepts from the official mock paper and are the likeliest to reappear. The remaining thirty-seven are predictions drawn from manual content the official mock never touched.

Answer options are shuffled on every attempt. The authored key leaned heavily toward B, and a fixed order would teach position-guessing rather than the material.

## Disclaimer

This is an **unofficial** study aid. It is not produced by, endorsed by, or affiliated with CCSD Council, Bridgit Malaysia, Bursa Malaysia, GRI, the ISSB, or any other body named in the questions.

Questions are original wordings written to test concepts from the course syllabus. They are not reproductions of any real exam paper. Page references point to the course manual purely so learners can locate the underlying source material, which is not included in this repository.

Nothing here guarantees a pass. Verify anything that matters against the primary standards themselves.
